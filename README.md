# meeting-notes

> 会议纪要：会开完不记录，等于没开。

## 简介

这里存放各类会议的纪要。目标不是逐字复述，而是让没参会的人看完也能知道：定了什么、谁负责、什么时候交。

## 目录结构

| 目录 / 文件 | 说明 |
| --- | --- |
| `weekly/` | 周会、例会纪要 |
| `project/` | 项目专项会议纪要 |
| `one-on-one/` | 一对一沟通记录 |
| `templates/meeting-template.md` | 纪要模板 |

## 纪要格式

每份纪要统一六段，写不出来的就留空并标 `待补充`：

```markdown
# [会议主题] YYYY-MM-DD

- 参会：
- 议题：本次要解决的三个问题（超过三个说明会开太长）
- 结论：逐条写明最终决定
- 待办：事项 / 负责人 / 截止时间
- 未决：没谈拢的问题，及下一步谁推动
- 下次：待续议题
```

## 写作原则

- 只记结论和行动项，不记讨论过程
- 每条待办必须有负责人和截止时间，否则不算待办
- 会后 24 小时内发出，越晚信息损耗越大
- 有争议但没结论的，如实写"未决"，不要粉饰成共识
